# precipitation_xunteng

北京小时降水量图，一个文件装完。

双击 `map_view_template.html` 打开，不用装东西、不用联网。色块、时刻滑块、色阶图例、
统计面板、右下角 256×256 参考小图全都在 —— 8 张色块图和帧数据都内联在文件里了。

底图要联网才显示；离线时自动换成经纬网加行政区轮廓，降水色块不受影响。

## 能干什么

- 拖滑块或点前后帧，在 11:00 / 12:00 两帧之间切
- 色阶 7 档，从零至小雨到特大暴雨，可切换首档透明或白色
- 调色块透明度、缩放回降水区范围

## 注意

这是成品不是模板。文件里原本的数据注入点早就填掉了，出图脚本和算法引擎也不在这个
文件夹里。想换一批数据重新出图，得从 git 历史把 `build_single_html.py` 和 `urban_area/`
的引擎取回来，再把注入点加回去。
